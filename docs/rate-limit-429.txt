--- the hint an assistant is handed ---

The server does not pass the raw problem+json through. It wraps every HTTP error
as {"error", "detail", "hint"} and writes a different hint per status, so the
assistant knows whether waiting will help. puntersedge_mcp 0.2.1 server.py:90-98:

    hints = {
        402: ("Monthly credit limit reached. This is NOT a rate limit and retrying will "
              "not help - see https://puntersedge.online/api/pricing. Tell the user."),
        429: ("Rate limited. Wait %s seconds and repeat the identical call."
              % (e.headers.get("Retry-After", "60") if e.headers else "60")),
        422: ("The request was malformed and was NOT billed. The detail names the bad "
              "parameter - fix it rather than retrying as-is."),
        401: "The API key is missing, wrong or inactive.",
        403: "This key's plan does not include this endpoint. The detail says which plans do.",
    }

That arrives with isError: false, like every other tool result. Branch on the
body, not the flag.
